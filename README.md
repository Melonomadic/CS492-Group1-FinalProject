**How to Contribute**

## How to Contribute

### Branch Naming
Never commit directly to `main`. Create a new branch for each task using the Task ID from the Sprint Planning sheet:

| Type | Format | Example |
|------|--------|---------|
| New feature | `feature/<TaskID>-<short-description>` | `feature/S01-T01-search-fields` |
| Bug fix | `fix/<TaskID>-<short-description>` | `fix/S01-T02-date-validation` |

### Commit Messages
Start every commit message with the Task ID, followed by a short description of the change:

```
S01-T01: add flight number search field
S01-T02: validate departure date is not in the past
```

### Pull Requests
When your task is ready, open a pull request into `main`. Every pull request must include:

- [ ] **Task ID:** the Sprint Planning task this work completes (e.g., S01-T01)
- [ ] **What changed:** a short summary of the work
- [ ] **How it was tested:** steps taken to confirm it works
- [ ] **Review:** approved by at least one other developer before merging
